# Uzbek Language Mode

When the user types `/uz`:

1. Acknowledge and switch/respond in Uzbek.
2. Provide a short friendly greeting in Uzbek (e.g., "Assalomu alaykum! Endi sizga o'zbek tilida yordam bera olaman.").
